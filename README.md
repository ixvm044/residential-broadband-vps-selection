## “住宅 IP”到底住宅在哪：ASN、原生 IP、双 ISP 三件事

判断一台美国住宅宽带服务器是不是真家宽，别看宣传词，看三个可验证的东西。

**第一是出口 ASN。** 普通美国 VPS 的出口通常落在机房自己的 ASN 上，比如某个数据中心运营商。丽萨主机西雅图这条线跑在 Atlas Networks 上，洛杉矶跑在 Astound Broadband 上，加州另外还有 T-Mobile / Frontier。第三方对西雅图的去程测试里，电信走 AS136190 > AS4134 > AS2914 > **AS21743**，联通走 AS4837 > AS3257 > **AS21743**，移动走 AS56041 > AS9808 > AS58453 > AS2914 > **AS21743**——三条路径最后都落在同一个 AS21743，也就是 Atlas Networks 的网络里。洛杉矶样本的去程末尾同样收在 AS398465（Astound）。这是“出口真的在宽带运营商那儿”最直接的证据，比任何“100% 模拟美国家庭”的文案都管用。

**第二是原生 IP。** 原生指的是这个 IP 由当地运营商直接分配给终端用户，而不是从别处租来再转售。公开的第三方测试里，西雅图样本和洛杉矶样本都被判定为原生 IP。

**第三是双 ISP 属性。** 同一个 IP 在检测库里能同时对应到两个 ISP 记录，通常出现在家宽段被多归属或转手的场景，是居民网络的典型特征。西雅图样本在第三方检测中被记录到双 ISP 属性。

物理层面，官方写得很直白：所有硬件托管在真实的美国家庭住宅房屋中，向当地宽带运营商申请安装光纤宽带。这句话解释了为什么它的套餐配置普遍不高——一台机器放在别人家客厅或储藏间里，能给你的核数和盘位本来就有上限。

然后把丑话说在前面：**住宅 IP 不等于万能过风控。** IP 被识别为住宅类型，只是消掉了“这是机房地址”这一层限制。账号本身的历史行为、登录设备、浏览器指纹、平台自己的规则，任何一条都能让你照样卡在验证页。更准确的理解是：它把网络环境这一项做到了接近真实美国家庭，剩下的部分要靠你自己。

**399 → 599，多花 200 元**：2 核 2G 40G / 100M 不限 变成 4 核 4G 80G / 200M 不限，资源和不限流量同时翻倍。

**禁止的用途写得很清楚。** 垃圾邮件、邮件群发、攻击扫描、钓鱼诈骗、资源滥用，一经发现或被投诉可能直接停机且不退款。住宅 IP 的价值建立在 IP 信誉上，投诉多了整段资源都受影响，商家在这件事上没有商量空间。

**“不限流量”不等于没有限制。** 页面标注的是月流量不设额度，仍受网络资源和滥用政策约束。把它理解成“可以随便跑任何类型的业务”是错的。

**Windows 要工单装，纽约 NAT 落地机系统很老。** 静态住宅 VDS 支持 Windows，但需购买后提交工单；纽约 NAT 落地机是 OpenVZ，只有 CentOS 7 或 Debian 8，也要工单重装。习惯开机自选镜像的人会不习惯。

**明确不适合的人**：面向中国大陆用户的网站；对延迟和丢包极敏感的实时应用；需要长期稳定大流量传输又不能接受波动的业务；必须拿到现金退款而不是余额；需要批量 IP 做矩阵；需要发邮件、做外呼这类高投诉业务。最后这一类，就算套餐写着不限流量也不代表可以用。

## 常见问题

**这些机器是真的家庭宽带吗？**
按官方产品页描述，硬件托管在真实美国家庭住宅中，接入当地光纤宽带运营商（西雅图 Atlas Networks、洛杉矶 Astound Broadband、加州 T-Mobile/Frontier），第三方测试中检出原生 IP 与双 ISP 属性，去程路由落在对应运营商的 ASN 上。这是目前能公开验证到的程度。

**能解锁 Netflix、TikTok 吗？**
公开测评里，西雅图样本曾测试通过 TikTok、Disney+、YouTube、Amazon Prime Video、Spotify；洛杉矶样本解锁 Disney+、Netflix、YouTube、Prime Video。但解锁是 IP 的实时状态，换 IP、换时间结果可能不同，也没人能对“所有账号所有时刻”打包票。把它当成“大概率可用、需自行验证”更准确。

**国内访问延迟多少？**
第三方测试机当时记录的三网平均 Ping 在 250ms 上下，电信约 201ms、联通约 220ms、移动约 327ms，更早的测试平均约 218.6ms。官方自己说这不是大陆优化线路，建议中转 + BBR。要低延迟，别在这条线上找。

**能退款吗？**
西雅图家宽 VDS 属特殊产品，仅退网站余额，不适用首页的 48 小时退款。纽约 NAT 家宽产品明确无退款。下单前把这条当成硬条件看待。

**169 元和 399 元怎么选？**
169 元是 1 核 1G / 3TB 固定流量；399 元是 2 核 2G / 100Mbps 不限流量。如果你每月只跑几百 GB，169 元更划算；如果确实会长期压着 6TB 上限，399 元的不限流量结构才成立。这不是性能高低，是计费模型的区别。
